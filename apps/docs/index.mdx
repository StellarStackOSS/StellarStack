StellarStack is a self-hosted control panel for managing Docker-based game
servers. It's the same problem space as Pterodactyl or Multicraft — but
built from a clean slate, with its own vocabulary and code, and designed
for how operators run servers in 2026: browser-direct daemon sockets,
blueprint-driven readiness, server splitting, and a panel that's pleasant
to live in.

This site is the operator's manual. If you want the elevator pitch and the
roadmap instead, head over to [stellarstack.dev](https://stellarstack.dev).

## What StellarStack does

<Steps>
  <Step title="Hosts the panel">
    Auth, dashboards, blueprint catalog, allocation pool, audit log. Lives
    in your browser, talks REST to the API.
  </Step>
  <Step title="Runs your nodes">
    A small Go daemon owns Docker on each host. Browsers dial the daemon
    directly over WebSocket for console, stats, and SFTP — no panel
    middleman to bottleneck.
  </Step>
  <Step title="Drives the lifecycle">
    Power actions block on real readiness signals. Backups archive the
    bind-mount and stream to S3 if you want. Schedules run as flow graphs
    with explicit wait gates.
  </Step>
</Steps>
