When the in-browser file manager isn't enough — bulk operations,
desktop tools (Cyberduck, Transmit, FileZilla), or `rsync` — use SFTP.

## Connection details

**Server → Files → SFTP details** shows:

| Field    | Value                                                  |
| -------- | ------------------------------------------------------ |
| Host     | The daemon node's FQDN.                                |
| Port     | Per-node SFTP port (default `2022`).                   |
| Username | `<your-panel-email>.<server-uuid-short>`               |
| Password | Use **Generate password** in the panel. One per user.  |

The username encodes the panel user + server, so the daemon can route a
single SFTP listener to the correct server's bind-mount and enforce
your subuser scope.

## Authentication

SFTP credentials are **scoped JWTs in disguise** — the daemon doesn't
maintain a Linux user per panel user. When you click **Generate
password**, the panel mints a long-lived (24h) JWT, hashes it, stores
the hash, and shows you the raw value once.

Subsequent password generations invalidate the previous one. There's no
"list active SFTP sessions" — sessions terminate when the JWT expires
or you generate a new password.

## What you can do

| Action               | Allowed                                                    |
| -------------------- | ---------------------------------------------------------- |
| Read files           | Yes (with `files.read` scope).                             |
| Write / upload files | Yes (with `files.write`).                                  |
| Delete files         | Yes (with `files.write`).                                  |
| `chmod` / `chown`    | No — the daemon ignores mode/owner changes.                |
| Symlink anywhere     | Refused if the target escapes the server's root.           |
| Run remote commands  | No — `ssh user@host command` is denied.                    |

## Performance

Throughput is direct daemon ↔ client — there's no panel hop. On a 1 Gbps
link a Minecraft world (~2 GB) uploads in roughly 30 seconds. We've
clocked 800 Mbit/s sustained on bare-metal hosts.

## Disabling SFTP per server

Admins can disable SFTP on a per-server basis (**Server → Settings →
Disable SFTP**). Useful for high-security multi-tenant deployments
where you only want files manipulated through audit-logged in-panel
operations.
